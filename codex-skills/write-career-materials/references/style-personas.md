# 风格画像与人物映射

## 总体共性

这批材料的共同点不是“写得长”，而是把个人工作写成了高价值问题、关键判断、机制方案、量化结果和长期资产。
默认先按这个共性成稿；只有在用户点名风格时，才进一步偏向某个人。

## 风格簇

### 1. 平台架构型

代表：魏臻、李家睿、张楠浠、王申宇

适合：

- 多端平台
- 统一架构
- 底座能力
- 协议/接入层
- 平台迁移与治理

标志动作：

- 先定义挑战类别，再讲架构判断。
- 强调统一、分层、复用、协议、平台基座。
- 把功能建设写成长期能力建设。

风险：

- 容易写得过抽象，必须补角色边界和结果指标。

### 2. 端到端落地型

代表：李相前

适合：

- 调度链路
- 产品闭环
- 运营链路
- 社区/推荐/报表

标志动作：

- 先讲业务问题，随后重点展开个人职责列表。
- 强调“我打通了哪条链路”“我建设了哪些关键模块”。
- 经常用任务量、成功率、覆盖量证明落地规模。

风险：

- 容易细节过多，要记得把模块串成主线。

### 3. 核心策略型

代表：罗正昕

适合：

- Agent 框架
- 算法策略
- 评测体系
- 复杂任务成功率提升

标志动作：

- 把难点定义得像论文摘要。
- 写“原有范式的根本缺陷”和“为什么新策略更优”。
- 同时关注效果、稳定性和成本。

风险：

- 容易写成研究记录，要补真实业务落地和用户规模。

### 4. 工程底座与产品形态型

代表：张天行

适合：

- 构建发布
- 远程开发
- 复杂交付
- 新产品形态探索

标志动作：

- 把隐性基础设施写成业务节奏的关键前提。
- 同时写工程难点和产品演进方向。
- 强调没有这条底座，前台增长和产品节奏跑不起来。

风险：

- 不要只剩“幕后支持感”，一定要把它连到业务窗口期和用户迁移。

### 5. 经营推进型

代表：唐辉

适合：

- 从 0 到 1 产品
- 增长迁移
- 跨团队推进
- 客户支持与外部影响力

标志动作：

- 从市场、行业或竞争格局起笔。
- 把技术、产品、增长、运营放进同一条主线。
- 敢写方向判断、节奏组织和规模推进。

风险：

- 容易写太满，要确保每条主张都能落回个人事实。

### 6. 体验治理型

代表：余芝君

适合：

- 高频用户路径
- 统一渲染/交互
- 组件重构
- 第三方风险治理

标志动作：

- 常用“背景与挑战 / 核心贡献 / 项目业绩”三段式。
- 把体验问题提升为统一机制问题。
- 强调旧方式不可持续，因此需要治理或重构。

风险：

- 指标通常不多，更要突出“问题不再发生”“治理闭环”“能力可扩展”。

### 7. 稳定性治理与上下文工程型

代表：孙浩

适合：

- 长链路稳定性
- 超时与失败语义
- 上下文治理
- Hooks/切面/审计底座

标志动作：

- 从底层矛盾写起，而不是从功能写起。
- 喜欢分层治理、递进结构、版本演进。
- 先解释为什么不能直接照搬业内方案，再说明工程权衡。

风险：

- 如果没有把根因和恢复链路讲清楚，就会显得只是在列 case。

## 个人指纹

### 魏臻

- 关键词：多端体系、质量闭环、组织协作、平台化
- 语气：负责人、架构说明书、分层结构明显
- 特别适合：你想把工作写成“平台体系与长期能力建设”

### 唐辉

- 关键词：方向判断、增长、迁移、客户、奖项、行业影响
- 语气：项目经营者
- 特别适合：你确实承担了产品路径和推进节奏

### 李相前

- 关键词：链路打通、调度、回调、推荐、报表、治理闭环
- 语气：直接、实干、职责密集
- 特别适合：你能清楚列出自己扛住的核心模块

### 孙浩

- 关键词：分层治理、超时语义、工程权衡、演进轨迹
- 语气：根因分析强、方法论强
- 特别适合：稳定性和底层机制项目

### 余芝君

- 关键词：高频路径、统一机制、渐进重构、体验治理
- 语气：稳、克制、三段式明显
- 特别适合：把体验问题写成可持续机制建设

### 李家睿

- 关键词：业务方案、技术方案、跨端复用、指标体系
- 语气：结构完整、收口稳
- 特别适合：基础能力建设和跨端平台项目

### 张楠浠

- 关键词：三层架构、统一平台、零停机迁移、系统治理
- 语气：负责人 + 后端平台治理
- 特别适合：统一架构、迁移、平台重构

### 张天行

- 关键词：版本工程、远程迁移、产品形态升级、工程底座
- 语气：工程底座和产品节奏并重
- 特别适合：交付链路和形态演进项目

### 王申宇

- 关键词：方案取舍、宿主一致性、CLI/Runtime、上下文效率
- 语气：设计评审稿、判断密度高
- 特别适合：协议层、接入层、统一运行时项目

### 罗正昕

- 关键词：Agent Loop、多智能体、Memory、评测、成功率
- 语气：策略升级、范式升级
- 特别适合：算法策略和框架升级项目
